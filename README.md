DSA Mini Project – Student Record Management System

📌 Project Overview

The Student Record Management System is a mini project developed using the C programming language and Data Structures and Algorithms (DSA). It helps manage student information, such as student ID, name, and marks, in an organized way.

The project demonstrates the practical use of data structures and basic operations for storing and managing student records.

🎯 Objectives

- To understand the practical implementation of DSA concepts.
- To store and manage student records efficiently.
- To perform insertion, searching, displaying, and deletion operations.
- To improve programming and problem-solving skills using C.

🛠️ Technologies Used

- Programming Language: C
- Concepts: Data Structures and Algorithms
- IDE: Visual Studio Code
- Version Control: Git and GitHub

✨ Features

- Add new student records.
- Display all student records.
- Search for a student record.
- Update student information.
- Delete student records.

Note: Features depend on the operations implemented in your source code.

📚 DSA Concepts Used

- Structures ("struct")
- Arrays or linked lists
- Searching
- Sorting (if implemented)
- Functions
- Loops and conditional statements

▶️ How to Run the Project

1. Clone this repository:
   git clone YOUR_GITHUB_REPOSITORY_URL
2. Open the project folder in Visual Studio Code.
3. Open the terminal in the project folder.
4. Compile the C program:
   gcc main.c -o student_records
5. Run the program on Windows:
   .\student_records.exe

Note: Replace "main.c" with your actual C source filename if it is different. GCC must be installed to compile the program.
